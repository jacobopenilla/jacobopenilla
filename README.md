## What I'm building

**Pregón** is an AI chat that helps small businesses sell online. You open one conversation, say what you want to sell, and it handles the hard parts: the store, the ads, the videos and the payments, with a human in the loop while we automate.

> We believe selling online should be as easy as selling candy at school.

Private repo, MVP in progress. Stack: Next.js, Tailwind, shadcn/ui, Supabase, Shopify OAuth.

## What I've built

- **[Nightly Meta Ads + Shopify autopilot](https://github.com/jacobopenilla/meta-ads-autopilot)**: a cloud routine that audits campaigns every night, applies kill rules at 90% of each threshold and sends a short plain-text report by email.
- **Auto-capture second brain**: Claude Code hooks that write every work session into an Obsidian vault, so context is never lost between sessions.
- **AI creative pipeline**: ad images and videos generated through APIs, plus a Remotion + Whisper editor with word-by-word captions, silence cuts and zooms.
- **COD e-commerce toolkit**: Shopify landing pages with cash-on-delivery checkout for Colombia, and research on integrating Dropi.
